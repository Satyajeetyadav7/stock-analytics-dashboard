# Real-time Stock Market Analytics Dashboard

## 📊 Project Overview

A professional-grade **Real-time Stock Analytics Dashboard** built with Python, Streamlit, and live data streaming from Yahoo Finance. This project demonstrates expertise in data engineering, visualization, and analytics—essential skills for data analytics roles.

### Key Features
- ✅ **Real-time Data Streaming**: Live stock prices updated automatically
- ✅ **Technical Analysis**: RSI, MACD, Moving Averages (SMA/EMA)
- ✅ **Multi-Stock Comparison**: Compare performance across multiple tickers
- ✅ **Interactive Visualizations**: Candlestick charts, trend analysis
- ✅ **Professional Insights**: Buy/Sell signals based on technical indicators
- ✅ **SQL Database Integration**: Historical data storage and retrieval
- ✅ **Responsive UI**: Mobile-friendly dashboard

## 🚀 Quick Start

### Installation Steps:

```bash
# 1. Clone the repository
git clone https://github.com/your-username/stock-analytics-dashboard.git
cd stock-analytics-dashboard

# 2. Create virtual environment
python -m venv venv
source venv/bin/activate

# 3. Install dependencies
pip install -r requirements.txt

# 4. Run the application
streamlit run stock_analytics_app.py
```

The app will open at `http://localhost:8501`

- Volatility analysis

### 4. **Market Insights Tab**
- Automated buy/sell signals
- Trend identification
